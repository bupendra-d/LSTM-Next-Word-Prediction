# LSTM Next-Word Prediction
A learning-based NLP project that predicts possible next words using an LSTM neural network trained on Shakespeare's *Hamlet*.


### Live Demo
[Try the Next-Word Prediction App]
https://lstm-next-word-prediction-c3dibh75csqhypwjrb8udb.streamlit.app/


### Limitations
This is a basic learning project built to understand LSTM-based language modeling. Predictions may be inaccurate, repetitive, or contextually irrelevant because the model is trained on a small, single-text corpus. Suggested words are not guaranteed to be correct.
